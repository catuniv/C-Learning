# 00_Basics

C 기본 문법, 배열, 함수, 포인터의 기초 개념을 복습했다.

---

## 1. min_max.c

### 문제
정수 5개를 입력받아 최댓값과 최솟값을 구한다.

### 핵심 개념
- 배열
- 반복문
- 조건문
- scanf와 주소 연산자 `&`

### 어려웠던 점
`scanf("%d", numbers[i])`가 아니라
`scanf("%d", &numbers[i])`를 사용해야 하는 이유가 헷갈렸다.

`scanf`는 값을 저장할 메모리 주소가 필요하기 때문에
`&numbers[i]`를 전달해야 한다.

## 2. find_max.c

### 문제
배열을 함수에 전달하여 최댓값을 반환한다.

### 핵심 개념
- 함수
- return
- 배열의 함수 전달
- `int numbers[]`와 `int *numbers`

### 어려웠던 점
함수를 호출할 때는 `numbers`를 전달하는데,
함수에서는 `int numbers[]`로 받는 부분이 헷갈렸다.

배열 이름 `numbers`는 함수 호출 시 첫 번째 원소의 주소처럼 사용되며,
함수 매개변수의 `int numbers[]`는 사실상 `int *numbers`와 같다.

## 3. swap.c

### 문제
두 변수의 주소를 함수에 전달하여 값을 서로 교환한다.

### 핵심 개념
- Call by Value
- 포인터
- 주소 연산자 `&`
- 역참조 연산자 `*`

### 어려웠던 점
`int *number1`과 `*number1`의 의미를 구분하는 것이 어려웠다.

- `int *number1` : 주소를 저장할 포인터 변수 선언
- `number1` : 저장된 주소
- `*number1` : 해당 주소에 저장된 실제 값

---

## 4. array_modify.c

### 문제
배열을 함수에 전달하고 모든 원소에 10을 더한다.

### 핵심 개념
- 배열과 포인터
- 함수에서 원본 배열 수정
- 포인터 연산

### 어려웠던 점
일반 변수는 `&`를 사용해야 원본을 수정할 수 있는데,
배열은 `addTen(numbers, size)`처럼 전달해도 원본이 변경되는 이유가 헷갈렸다.

배열 이름이 첫 번째 원소를 가리키는 주소로 변환되어 전달되기 때문이다.

또한 다음 두 표현이 같다는 것을 학습했다.

`numbers[i]`

`*(numbers + i)`

# FINAL PROBLEM

## FINAL_PROBLEM.c

### 문제
5명의 학생 × 3과목의 성적을 관리한다.

#### 난이도
브론즈 상

함수를 이용하여:
- 보너스 점수 +5
- 100점 초과 방지
- 학생별 총점 계산
- 학생별 최고점 계산

### 핵심 개념
- 2차원 배열
- 함수
- 포인터
- 배열을 함수에 전달
- 함수에서 배열 수정
- return
- sizeof
- 중첩 반복문

### 어려웠던 점

2차원 배열에서 한 학생의 점수만 함수에 전달할 때

`info[student]`

를 전달한다는 부분이 어려웠다.

`info[student]`는 해당 학생의 한 행을 의미하며,
함수에서는 이를 1차원 배열처럼 받을 수 있다.

또한 보너스를 더한 결과가 100점을 넘으면
100으로 제한하는 처리가 필요했다.
