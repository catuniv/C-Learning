# C-Learning

자동차 임베디드 소프트웨어 개발을 목표로 C 언어를 기초부터 심화까지 복습하고 기록하는 저장소입니다.

단순히 문법을 암기하는 것이 아니라 직접 코드를 작성하면서
포인터, 메모리, 자료구조, 비트 연산 등 C의 핵심 개념을 이해하는 것을 목표로 합니다.

최종적으로는 STM32와 CAN 통신 등 임베디드 환경에서 C를 자유롭게 사용할 수 있는 수준까지 학습합니다.

---

## 학습 방식

각 단원은 다음 순서로 진행합니다.

1. 핵심 개념 학습
2. 기본 Practice 문제
3. 응용 문제
4. 백준 / COS Pro 스타일 종합 문제
5. 학습 내용 및 어려웠던 점 정리

각 단원의 마지막에는 `FINAL_PROBLEM.c`를 통해
해당 단원에서 학습한 내용을 종합적으로 복습합니다.
